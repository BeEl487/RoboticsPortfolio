# Game Design

Alongside robotics, I have a long-running passion for game design, built mostly through solo entries into timed game jams. Each jam forces the same discipline that shows up in my robotics work: a fixed deadline, a fixed scope, and no room to over-engineer.

[beeel.itch.io](https://beeel.itch.io/)
